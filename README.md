# News Image 01 - 13 November 2026 World News Infographic

Sum up 13 November's world news in one 1024x1024 PNG image.

## Contents
- `entry.png`: 1024x1024 PNG infographic summarizing world news of Friday 13 November 2026 (Europe-Ukraine peace talks, Iran tanker claims, Microsoft Outlook outage, Nvidia CEO developments, inflation/Bitcoin, Starship launch, FAA flight groundings, sports/culture ticker).
- `main.py`: Python script that copies `entry.png` to the output directory specified by `MAKEFUN_OUTPUT_DIR` (defaulting to `/output`).
